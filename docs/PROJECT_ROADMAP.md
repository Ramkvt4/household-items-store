# HomeApplianceHub

## Project Overview

HomeApplianceHub is a responsive e-commerce website for selling household appliances such as TVs, Refrigerators, Washing Machines, Air Conditioners, Kitchen Appliances, and more.

The project is developed using HTML, CSS, JavaScript and Firebase.

---

# Technology Stack

Frontend
- HTML5
- CSS3
- JavaScript (ES6 Modules)

Backend
- Firebase Authentication
- Firebase Firestore

Hosting
- GitHub Pages

Version Control

- GitHub
